Prompt 1

Vou fazer um exercício em Java usando padrão Command com store e load para automação residencial. Como devo organizar as pastas e interfaces?

Ficou assim: uma pasta src com o pacote command (interface Command) e um pacote device para os dispositivos. A interface Command estende Serializable porque os comandos vão ser gravados em disco, e por enquanto só tem o execute().

Prompt 2

Me ajuda a implementar os 7 dispositivos do diagrama de classes de forma bem simples, só para simular o estado de cada um.

Mudei duas coisas no que veio. Coloquei Serializable em todas as classes, porque os comandos guardam uma referência para o dispositivo e vão ser gravados em disco. E mantive cada classe enxuta, só com os métodos do diagrama, um campo de estado e um println para mostrar o que aconteceu. Também marquei o estado como transient, assim quando o dispositivo é lido do disco ele volta zerado, como se tivesse faltado luz, e só o histórico de comandos reconstrói o estado.
